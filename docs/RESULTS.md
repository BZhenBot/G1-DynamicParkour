# 能力、证据与研究边界

问题是在三个有真实碰撞的平台上组合子策略，完成两跳及稳定恢复；终台以滑轨动力学横移。原验收基线commit为`76f70239b707d1b33b29ec823ab56352692ce922`。本次整理没有重新训练策略，不把历史结果当作本次新实验。

每跳要求原源台双足支持至少0.1s、无支持时向上速度>0.1m/s、真实AIR≥0.08s且升高≥0.03m、合法目标接触及原连续2s稳定；同时检查足边界、速度、姿态、非法支持和动力学。完整路线仅起点reset，协调时不写qpos/qvel、关节状态或动作历史；准备步态不能冒充第二跳。

Jump为源25Hz动作保持，恢复/准备50Hz，物理200Hz。平台参考由实际驱动器实现，接触和实测轨迹独立核验。持续奖励按RewardManager真实dt缩放；一次性事件奖励以事件差分和除dt补偿，见对应源码，reward不代表成功。

Jump/Recovery Actor114：99维本体/实际动作历史、当前目标相对状态6、公开技能时钟1、无表面身份接触/力8。准备Actor103为当前99维加当前起跳点相对位置/朝向4。协调器额外读取当前足FK及过去支持历史，不使用未来真实轨迹或验收FSM。训练Critic130中的当前任务phase、几何/平台sin-cos等特权，以及准备Critic专用输入，见源码和原技术报告；部署不用Critic。
