# 发行决策日志

| 决策 | 证据 | 最小处理与验证 |
|---|---|---|
| 独立目录/新Git | 原HEAD、历史和未跟踪记录须保护 | 新仓库，无原历史，前后哈希/refs/状态比较 |
| 能力限V2.2 | 正式76/100，V3未正式完成 | 不复制V3模块或宣称完成 |
| MIT/集体署名 | 用户确认原创发布权并选择MIT | 不推断个人姓名、邮箱 |
| G1/视频隔离 | 精确资产来源权利未闭合 | 不入Git或允许发布ZIP |
| 权重外置 | 六部署角色还依赖构造先验 | 十权重角色、路径、SHA闭包 |
| 结果去身份化 | 原文有机器路径 | 原/新SHA并列，原proof保持语义 |
| 区分安装证据 | 联网失败、离线成功 | 外部获取限制保留 |
| 停在本地 | 用户要求最终审核 | 无远端，无GitHub写操作 |

最终校验采用Windows副本自身src和新独立env，WSL1/1、Windows同seed0/1不合格，差异原因待调查。完整视频解码与版权许可分开判断。
